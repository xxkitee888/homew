\# Code Portfolio



Учебный репозиторий для хранения домашних заданий, практик и проектов по курсам.



\## Структура репозитория



\- \*\*course-1\*\*, \*\*course-2\*\*, \*\*course-3\*\* — три учебных курса.

\- В каждом курсе три раздела:

&#x20; - `homeworks` — домашние задания;

&#x20; - `practices` — практические работы;

&#x20; - `projects` — итоговые проекты.



\## Правила ведения репозитория



\- Временные файлы сборки (`bin/`, `obj/`) и настройки IDE не коммитятся — см. `.gitignore`.
